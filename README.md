# Tzschk's GB Studio Plugins
A few odd scene types for GB Studio. Currently tested up to v4.2.2.

## Simple Car

https://github.com/user-attachments/assets/e9d0caa2-bf08-4811-9463-6ebe1ec19dd7

A simple vehicular player type with 360° movement. Use left/right to turn and A/B (configurable) to accelerate, brake, and reverse.

Use the "Fixed Direction" animation type with one frame for however many visual directions you'd like.
<img width="1029" height="103" alt="image" src="https://github.com/user-attachments/assets/7a1777ed-63d8-44cd-aa23-3b390e265a5c" />

Inputs, acceleration, deceleration, braking, and turning radius are configurable in settings.

## Simple Tank

https://github.com/user-attachments/assets/88429d3a-e076-4260-aa06-68908171181c

Similar to Simple Car, but even simpler. Classic tank controls: left/right to turn and up/down to move forward and backward.

Turn speed is configurable in settings.

## Vintage Platformer

https://github.com/user-attachments/assets/deda17e0-9e10-470c-9413-7c7a04b10302

A scene type based on early arcade platformers with beloved features such as:
- Fixed jump arc
- constant move speed, no acceleration
- Complete momentum loss when falling

Jump speed, climb speed, max fall speed, and gravity are adjustable in Settings. Horizontal movement uses actor's speed.

## Vintage Adventure

https://github.com/user-attachments/assets/b6b51c11-5bc1-409b-93e0-c938f25040d3

A scene type with grid-aligned movement based on the original Legend of Zelda.
There are two movement styles available in Settings:
- Strict: cardinal only alignment (true to LOZ)
- Smooth: player aligns diagonally for smoother movement (A bit like Pac-Man)
